# Florería - Aplicación Móvil (Android)

Aplicación móvil nativa desarrollada en **Android Studio (Java / XML)** para la gestión y administración del catálogo de productos de una florería.

## Funcionalidades Implementadas
- **Módulo de Administración (`Admin.java`):** Gestión de inventario y control de productos.
- **Listado Dinámico:** Implementación de `RecyclerView` con adaptador personalizado (`ProductoAdminAdapter`).
- **Interfaz de Usuario:** Vistas diseñadas bajo los lineamientos de **Material Design** (`item_producto_admin.xml`).
- **Navegación y Pantallas:** Flujo de acceso y vistas principales de la aplicación.

## Tecnologías Utilizadas
- **IDE:** Android Studio
- **Lenguaje:** Java / XML
- **Control de Versiones:** Git & GitHub
- **Sistema de Construcción:** Gradle (Kotlin DSL)

## Instalación y Ejecución
1. Clonar el repositorio:
   `git clone https://github.com/250020092-ops/Floreria.git`
2. Abrir el proyecto en **Android Studio**.
3. Esperar la sincronización de **Gradle**.
4. Ejecutar en un emulador (AVD) o dispositivo físico Android.
